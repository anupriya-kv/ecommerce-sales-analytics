E-Commerce Customer Behavior & Cohort Analysis

Project Objective:
This project analyzes e-commerce customer purchasing behavior using Python, data analytics, and cohort analysis techniques. The project focuses on customer retention, sales trends, product performance, and customer segmentation.

Technologies Used:
- Python
- Pandas
- Matplotlib
- Seaborn
- Power BI

Dataset:
Online Retail II Dataset

Features Implemented:
- Data Cleaning
- Exploratory Data Analysis
- Monthly Sales Trend Analysis
- Top Products Analysis
- Country-wise Sales Analysis
- Customer Segmentation
- Cohort Analysis
- Retention Heatmap

Project Structure:
- dataset/ : dataset files
- python/ : Python scripts
- screenshots/ : generated charts and outputs

How to Run:
1. Open project folder in VS Code
2. Run data_cleaning.py
3. Run eda_analysis.py
4. Charts and outputs will be generated automatically
